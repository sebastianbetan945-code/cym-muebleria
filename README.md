# CyM Muebles — Sitio web

Ver la explicación completa (qué archivo es cada cosa, cómo editar precios,
fotos, WhatsApp, categorías, y cómo subirlo a GitHub/Netlify) en la
respuesta del chat. Este archivo es un resumen rápido.

## Archivos
- `index.html` — estructura de la página.
- `style.css` — todos los estilos y colores.
- `script.js` — configuración del negocio (`BUSINESS`) y productos (`products`).
- `images/` — fotos de demostración, reemplazables.

## Para probarlo
Abrí `index.html` con doble clic, o serví la carpeta con cualquier servidor
estático (Live Server de VS Code, `npx serve`, etc).
